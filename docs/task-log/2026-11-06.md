## 任务 2：修复"平台否认自身能力"（用户实测反馈，P0）

**目标**：用户三句自然请求（定时10分钟/去github找项目/自己进化功能）全部被 chat 人格否认——平台明明有闹钟、联网调研与进化闭环。

**根因**：①路由句式是开发者测试句式，没覆盖真实说法；②chat 人格 system prompt 不含平台能力清单，模型以"裸 GLM"身份如实否认平台实际拥有的能力（最恶劣失败形态：往"不能"方向撒谎）。

**实现方式**：
- 能力清单注入：converse() 动态取 active 能力 purpose + 触发说法示例 + 平台边界（能自动进化参数/半自动吸收开源、不能凭空写代码）写进 system prompt
- 路由补口："定时/倒计时 + N分钟"（无"提醒我"前缀）→ alarm；"github + 找/搜/高星"（无仓库URL）→ deep_research
- 语义修正：裸"N分钟/N小时"（无"每/每隔/后"）= N 分钟后一次性（此前 LLM 兜底误判为循环 interval）
- 闹钟内容剥离补"定时一个任务/设个倒计时"句式

**修改明细**：
- `server/aster/chat/service.py:34-58` _capability_manifest + converse 注入
- `server/aster/orchestrator/core.py` classify 两条新规则；`server/aster/scheduler.py` 裸时长=date 规则；`server/aster/api/chat.py` 剥离句式

**验证结果**：
- 用户原话三连：定时10分钟→闹钟（一次性 14:14 正确）；github找项目→deep_research；能力问询→人格如实答"能"并给用法
- 54 passed 零回归；误建的循环闹钟已清理
