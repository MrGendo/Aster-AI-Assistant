# 并行执行器设计（Spec）

- 日期：2026-11-05
- 用户授权：2026-11-05 对话确认（"确定"）——范围：能力运行独立连接、并发上限 3、DAG 无依赖步骤并行
- 状态：执行中（授权范围即本文件 §1）

## 1. 范围

1. `run_capability` 改为内部自开 sqlite 连接（写完即关）——消除跨线程共享连接的竞态根因
2. 计划路径执行器：依赖齐备的步骤并发执行，`PARALLEL_CAP = 3`；伪能力（llm_task/llm_verify）同样可并行
3. 语义保持：任一步骤失败 → 任务失败（fail-fast）；审批挂起/取消/总超时闸不变
4. 模板路径（单步）与回放实验共用新签名，行为不变

## 2. 不做

- 跨任务全局并发调度（多任务各自独立，天然并发已存在——FastAPI 后台任务）
- 连接池（单用户规模，开关连接成本可忽略）

## 3. 验收

1. 27+ 项测试全绿（回归无破）
2. 真实计划任务含两个无依赖步骤时，runs 时间戳证明重叠执行
3. 串行链（仓库分析→摘要）行为不变
